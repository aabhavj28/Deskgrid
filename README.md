# Deskgrid

**Deskgrid** is a responsive storefront-style website prototype for exploring PC and laptop accessories. It features a product catalogue, category filters, an interactive keyboard demo, and responsive layouts.

## Features

- Responsive storefront interface for desktop and mobile layouts
- Product catalogue with sample accessory listings
- Category filtering for browsing products
- Interactive keyboard demo (keyboard input and on-screen interaction)
- SVG-based visuals and UI animations
- Scroll effects and counters
- Focus styling and reduced-motion considerations

## Built With

- **HTML5** — page structure
- **CSS3** — styling, layout, responsiveness, and animations
- **JavaScript** — interactive features and filtering
- **SVG** — scalable illustrations

## Getting Started

This is a front-end prototype and does not require a server or database to run locally.

1. Clone the repository:

   ```bash
   git clone https://github.com/aabhavj28/Deskgrid.git
   ```
2. Open the repository folder.
3. Open `index.html` in your browser.

## Project Scope & Limitations

Deskgrid is currently a front-end prototype. It does **not** include a backend, database, user authentication, live inventory, checkout, payment processing, or order management. Product listings and related content are sample/illustrative data.
